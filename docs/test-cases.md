## 测试发现的问题

键盘事件最初使用 `animateClick()` 触发按钮。该方法会延迟发出点击信号，快速输入
`12.5+3.2` 时可能出现按键处理顺序异常，自动化测试曾得到错误结果 `51`。修复方法是
改用同步的 `click()`：键盘仍复用按钮的 `clicked` 信号，但每个按键会按接收顺序立即
处理。修复后所有测试通过。
