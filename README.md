# CalculatorLab1

Qt 应用程序开发课程实验 1：带键盘事件的计算器。

## 开发环境

- Qt 6.11.2
- Qt Creator 20.0.1 Community
- MinGW 13.1.0 64-bit
- CMake

## 功能

- 加、减、乘、除四则运算
- 小数输入、正负号、退格、清除当前项和全部清除
- 连续运算与连续操作符替换
- 除数为 0 和结果溢出提示
- 计算完成后输入数字自动开始新计算
- 鼠标与键盘复用按钮的 `clicked` 信号处理逻辑
- QSS 界面样式和按键状态反馈
- Qt Test 自动化交互测试

## 键盘操作

| 功能 | 按键 |
|---|---|
| 数字输入 | `0` 至 `9` |
| 小数点 | `.` 或 `,` |
| 四则运算 | `+`、`-`、`*`、`/` |
| 计算结果 | `Enter` 或 `=` |
| 退格 | `Backspace` |
| 清除当前项 | `Delete` |
| 全部清除 | `Esc` 或 `C` |

## 运行方法

1. 使用 Qt Creator 打开根目录的 `CMakeLists.txt`。
2. 选择 `Desktop Qt 6.11.2 MinGW 64-bit` Kit。
3. 配置项目后按 `Ctrl+R` 构建并运行。

## 设计说明

`MainWindow` 保存当前累计值、待执行操作符以及输入状态。鼠标点击直接触发按钮的
`clicked` 信号；键盘事件找到对应按钮后调用 `click()`，因此两种输入方式共用数字、
小数点、运算和异常处理代码，避免重复实现。

## 测试

项目包含 `CalculatorLab1Tests` 测试目标，覆盖输入编辑、普通运算、连续运算、操作符
替换、除零恢复、结果后继续输入以及鼠标键盘混合输入。测试用例详见
[`docs/test-cases.md`](docs/test-cases.md)。

在已经配置好的构建目录中运行：

```bash
ctest --output-on-failure
```
